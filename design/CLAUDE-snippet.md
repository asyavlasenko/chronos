# Фрагмент для CLAUDE.md проєкту Chronos

Скопіюй блок нижче в `CLAUDE.md` у корені репозиторію (або створи файл), щоб Claude Code
завжди будував UI за цим дизайном.

```markdown
## Дизайн

- Джерело правди для вигляду — папка `design/`: `design/README.md` (екрани, компоненти, поведінка),
  `design/tokens.css` (CSS-змінні) і `design/screens/*.html` (16 статичних мокапів).
- Перед тим як робити будь-який екран або компонент, відкрий відповідний файл у `design/screens/`
  і відтвори його структуру, відступи, радіуси та кольори точно. Не вигадуй нові кольори:
  використовуй тільки змінні з `design/tokens.css` (підключи його як `src/styles/tokens.css`).
- Шрифт Inter (Google Fonts, 400/500/600/700). Іконки — Lucide (тонкий stroke), без емодзі.
- Акцентний синій `--accent` лише для «сьогодні», лінії «зараз», фокусу й посилань.
  Головні кнопки темні (`--dark`), вторинні — білі з рамкою `--line`, усі кнопки-пілюлі.
- Події фарбуються кольором календаря (пара tint/text з tokens.css); у спільному календарі — кольором учасника.
- Три типи подій мають різний вигляд (див. таблицю в design/README.md): зустріч — тінт-блок,
  нагадування — біла пілюля з дзвіночком, задача — блок з чекбоксом.
- Навігація: хедер Огляд · Календар · Задачі · Календарі; у календарі перемикач День · Тиждень · Місяць · Рік;
  у тижні додатково Картки | Стрічка часу.
- Два способи створення події: модалка по кліку на вільний слот (`design/screens/11-event-quick-modal.html`)
  і окрема сторінка (`10-event-create.html`). Клік на подію — модалка деталей (`12-event-details.html`).
- Мобільна версія — `16-mobile.html`: нижня навігація, FAB «+», картки на всю ширину.
- Код стилів: CSS Modules або plain CSS зі змінними; інлайнові стилі з мокапів переносити у класи.
```
