## Act: Basic

**Дата початку:** 2026-11-06  **Дата завершення:** 2026-11-16

### Чеклист Basic (з ТЗ)

- [x] Реєстрація, вхід, вихід, скидання пароля
- [x] Головний календар створюється автоматично; не видаляється й не ховається
- [x] Додаткові календарі: назва, опис, колір; редагуються, ховаються, видаляються
- [x] Вбудований календар державних свят за країною з профілю (зовнішній API, кеш по країні+року)
- [x] Події трьох типів: arrangement (початок/кінець, дефолтна тривалість), reminder, task (виконано)
- [x] Обов'язкові поля події: назва, дата, календар
- [x] Два способи створення: клік на порожнє місце (без переходу) і кнопка (окрема сторінка)
- [x] Запрошення на подію по email
- [x] Спільні календарі: кілька користувачів створюють події в одному календарі
- [x] Кожен учасник обирає колір своїх подій; права owner/editor/viewer
- [x] Подання тиждень / місяць / рік; номери тижнів у тижневому поданні
- [x] Фільтр за категоріями (календарями/типами), пошук
- [x] Усі події клікабельні з прев'ю; відображення відповідно до тривалості
- [x] Прості форми створення; валідація всіх полів з повідомленнями
- [x] Адаптивність (mobile, tablet)
- [x] Сервіс не падає (обробка всіх помилок)
- [x] Docker: окремі контейнери для backend і frontend, docker-compose з базою, змінні середовища

**Що зроблено по тижнях:**
- 2026-11-06. Каркас репозиторію (backend, frontend, Docker, docs). Фронтенд зверстано за всіма 16 мокапами на тимчасових даних.
- 2026-11-16. Встановлено Docker і MongoDB, перевірено `docker compose up --build`. Реалізовано весь бекенд: auth, users,
  calendars, events, invites, holidays; 222 тести. Фронтенд переведено на API. Пройдено наскрізні сценарії в браузері:
  реєстрація, створення календаря і подій двома способами, задачі, запрошення на подію, спільний календар із ролями, мобільний вигляд.
  Додано seed демо-даних і скріншоти в README.

**Що далі:** відповіді на guiding questions, справжній SMTP для демо, пост для етапу Share, ідеї Creative з `docs/STATUS.md`.
